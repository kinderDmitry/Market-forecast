# Market Forecast PRO X — Google Sheets личный кабинет

Этот вариант не требует Supabase, VPS или отдельной базы. Google Таблица остаётся **закрытой**, а Google Apps Script выступает бесплатным HTTPS API между APK и таблицей.

## Что делает система

1. Пользователь регистрируется в APK.
2. Apps Script автоматически добавляет его в лист `Users`.
3. Новый пользователь получает `role=user`, `active=FALSE`, пустую дату окончания.
4. Администратор вручную открывает Google Таблицу и меняет `role`, `active` и `expires_at`.
5. APK при входе и периодической проверке получает актуальный статус.
6. Если `active=FALSE` или срок истёк — вход блокируется.
7. Пароль в таблице хранится только как SHA-256 хэш.
8. Токен сессии подписывается секретом Apps Script; сам секрет в таблицу не попадает.

## Шаг 1. Создать Google Таблицу

Создайте Google Sheets, например:

`Market Forecast PRO X — Users`

Вручную можно создать лист `Users` и первую строку:

| id | email | name | password_hash | role | active | expires_at | created_at |
|---|---|---|---|---|---|---|---|

Если лист не создать, скрипт создаст его автоматически при первом запросе.

### Как управлять пользователями

После регистрации строка будет примерно такой:

| id | email | name | password_hash | role | active | expires_at | created_at |
|---|---|---|---|---|---|---|---|
| MFP-ABC123 | user@mail.com | Ivan | ... | user | FALSE | | 2026-09-12... |

Ты меняешь только три поля:

- `role`: `user` или `admin`
- `active`: `TRUE` или `FALSE`
- `expires_at`: дата `2026-12-31` или пусто для бессрочного доступа

**Не изменяй** `id`, `password_hash` и `created_at`.

## Шаг 2. Создать Apps Script

В Google Таблице откройте:

**Расширения → Apps Script**

Удалите стандартный код и вставьте содержимое `Code.gs`.

## Шаг 3. Указать ID таблицы

ID находится в адресе Google Sheets между `/d/` и `/edit`.

Пример:

`https://docs.google.com/spreadsheets/d/ВАШ_ID/edit`

В Apps Script откройте:

**Project Settings → Script Properties → Add script property**

Создайте:

`SPREADSHEET_ID` = ID вашей таблицы

И второе свойство:

`APP_SECRET` = длинная случайная строка минимум 32 символа.

Например можно сгенерировать её любым локальным генератором случайных строк. Не публикуйте её в GitHub и никому не отправляйте.

## Шаг 4. Развернуть API

В Apps Script:

**Deploy → New deployment → Web app**

Настройки:

- Execute as: **Me**
- Who has access: **Anyone**

Нажмите **Deploy**.

Google выдаст URL примерно такого вида:

`https://script.google.com/macros/s/XXXXXXXXXXXXXXXX/exec`

Скопируйте именно URL `/exec`.

## Шаг 5. Подключить APK

В Market Forecast PRO X откройте:

**Настройки → Личный кабинет**

В поле:

**URL Google Apps Script**

вставьте URL `/exec` и сохраните его.

После этого APK будет работать через вашу таблицу.

## Шаг 6. Создать первого администратора

1. В APK зарегистрируй свой аккаунт.
2. В Google Sheets появится новая строка.
3. Найди её по email.
4. Поставь:

`role = admin`

`active = TRUE`

`expires_at` — оставь пустым для бессрочного доступа.

5. В APK войди заново.

Теперь этот аккаунт будет администратором.

## Обычный пользователь

Новый пользователь автоматически записывается как:

`role = user`

`active = FALSE`

`expires_at = пусто`

Он увидит сообщение, что доступ ожидает разрешения.

Ты после этого ставишь:

`active = TRUE`

и, если нужен ограниченный срок:

`expires_at = 2026-12-31`

После повторного входа доступ будет разрешён.

## Закрытие доступа

Поставь:

`active = FALSE`

При следующей серверной проверке APK заблокирует аккаунт.

## Изменение роли

Для администратора:

`role = admin`

Для обычного пользователя:

`role = user`

Роль сама по себе не открывает доступ: поле `active` тоже должно быть `TRUE`, а дата не должна быть просрочена.

## Безопасность

Google Таблица должна оставаться с доступом **Restricted / Ограниченный доступ**. Не публикуйте её и не давайте пользователям права на просмотр.

Apps Script выполняется от имени владельца и единственный имеет доступ к таблице.

Не размещайте `APP_SECRET` в GitHub.

Для коммерческого релиза рекомендуется дополнительно добавить rate limiting, Argon2id/scrypt вместо SHA-256 и подтверждение email. Текущая версия предназначена как простой бесплатный вариант личного кабинета.

## Важное ограничение

Google Apps Script имеет квоты Google. Для небольшого числа пользователей этого обычно достаточно, но это не безлимитный коммерческий VPS. Условия и квоты Google могут изменяться.
