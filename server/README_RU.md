# Бесплатный сервер личного кабинета Market Forecast PRO X

Вариант: **Cloudflare Workers + D1**. Это реальный HTTPS backend и база данных. GitHub хранит исходники и может запускать деплой, но GitHub Pages сам по себе сервером базы/авторизации не является.

## 1. Создать сервер
1. Создайте бесплатный аккаунт Cloudflare.
2. Установите Node.js и Wrangler на компьютере: `npm install -g wrangler`.
3. Войдите: `wrangler login`.
4. Перейдите в папку `server/cloudflare`.
5. Создайте D1: `wrangler d1 create market-forecast-prox`.
6. Скопируйте выданный `database_id` в `wrangler.toml` вместо `REPLACE_WITH_D1_DATABASE_ID`.
7. В `wrangler.toml` замените `REPLACE_WITH_YOUR_ADMIN_EMAIL` на ваш email. Именно этот email получает роль администратора.
8. Создайте таблицы: `wrangler d1 execute market-forecast-prox --remote --file=schema.sql`.
9. Опубликуйте: `wrangler deploy`.
10. Wrangler покажет HTTPS-адрес вида `https://market-forecast-prox-access.<ваш-аккаунт>.workers.dev`.

## 2. Подключить приложение
В приложении откройте **Настройки → Личный кабинет**, вставьте HTTPS-адрес Worker и зарегистрируйтесь своим admin-email. Первый аккаунт с `ADMIN_EMAIL` активируется автоматически и получает роль администратора.

Обычный пользователь регистрируется, но остаётся заблокированным до вашего разрешения. В разделе администратора вы включаете/выключаете доступ. При выключении активные сессии пользователя удаляются.

## 3. Что важно
- Не храните пароли в GitHub.
- В этом варианте пароль в базе хранится как SHA-256 хэш; для коммерческого релиза рекомендуется перейти на Argon2id/scrypt и добавить rate limiting/2FA.
- Бесплатность зависит от актуальных лимитов Cloudflare. Это не обещание безлимитного сервера: при превышении лимитов сервис может потребовать платный тариф.
- GitHub можно использовать для хранения кода и автоматического деплоя, но не как постоянную базу данных.
