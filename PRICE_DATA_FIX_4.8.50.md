# Market Forecast PRO X 4.8.50 — исправление единой цены

## Что исправлено
- Один канонический quote snapshot на инструмент для всех экранов и таймфреймов.
- Per-symbol lock исключает гонку сетевых запросов, когда старый ответ мог перезаписать более новый.
- Кэш котировки 8 секунд используется только для синхронизации отображения, а не для сглаживания цены.
- Убрана искусственная блокировка реального движения цены на 2.5%: цена от источника больше не подменяется старой ценой.
- Для российских акций источник текущей цены остаётся MOEX; история также не смешивается с Yahoo.
- Forecast Entry продолжает рассчитываться от того же live quote, который показывается в интерфейсе.
- Версия: 4.8.50, versionCode 93.

## Проверка
Проверены структура проекта, баланс скобок изменённого Kotlin-файла, наличие обязательных Gradle/Manifest файлов, версия и workflow. Полный Gradle assembleDebug в текущей среде выполнить невозможно: в среде нет Gradle Wrapper/установленного Gradle и нет сетевого доступа для его загрузки. Финальная компиляция должна быть выполнена GitHub Actions.
