# Market Forecast PRO X 4.8.83 — Google Sheets личный кабинет

- Личный кабинет переведён на простой бесплатный backend Google Apps Script + закрытая Google Sheets.
- Регистрация APK автоматически добавляет пользователя в лист Users.
- Новый пользователь получает role=user и active=FALSE.
- Администратор вручную меняет role, active и expires_at в закрытой таблице.
- Добавлена проверка срока доступа.
- Пароль не хранится открытым текстом: в таблицу записывается SHA-256 хэш.
- Добавлена подписанная серверная сессия с APP_SECRET.
- APK получает только публичные поля пользователя.
- Добавлена инструкция server/google_apps_script/README_RU.md.
- Добавлен готовый Google Apps Script: server/google_apps_script/Code.gs.
- Убран обязательный Cloudflare/D1 backend из сценария личного кабинета; его файлы сохранены отдельно для совместимости с предыдущей версией.
