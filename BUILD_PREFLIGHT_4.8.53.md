# Market Forecast PRO X 4.8.53 — BCS ONLY preflight

## Что изменено
- БКС стал **единственным источником рыночных данных** для котировок, свечей, каталога инструментов, прогнозов и сканера.
- Убраны runtime fallback на MOEX/Yahoo/Stooq/Alpha Vantage для market-data пути.
- Каталог и поиск инструментов переведены на BCS Information Service.
- Класс инструмента (`classCode`) теперь определяется через BCS, а не угадывается как TQBR.
- Исторические свечи используют официальные BCS таймфреймы: M1/M5/M15/M30/H1/H4/D/W.
- Live price и все таймфреймы используют одну BCS canonical quote.
- Индикатор источника показывает `БКС • единственный источник`.
- Обычный сканер больше не принимает пользовательский горизонт: срок действия сигнала автоматически соответствует выбранному таймфрейму.
- Сигнал записывается в scanner state сразу после подтверждения и отправляется уведомлением без ожидания окончания полного прохода.
- Срок действия ScanRow: 15M → 15 минут, 1H → 1 час, 4H → 4 часа, 1D → 1 день, 1W → 7 дней.
- Screenshot scanner в текущем исходнике отсутствует.

## Проверки, выполненные локально
- Проверена структура ZIP и исходников.
- Проверены паритет скобок в Kotlin-файлах.
- Проверено отсутствие runtime-вызовов MOEX/Yahoo/Stooq/Alpha Vantage в `MarketRepository` для market-data.
- Проверен Gradle-конфиг: `versionCode=95`, `versionName=4.8.53`.
- Полную Android Gradle сборку в текущем sandbox выполнить невозможно: в окружении отсутствуют Android SDK/Gradle wrapper. GitHub Actions использует Gradle 8.11.1 и Android SDK 36; перед публикацией APK сборка должна пройти без ошибок.

## Важное ограничение
БКС API требует действующий refresh-token. Без него приложение намеренно не переключается на другой источник и показывает, что БКС не подключён.
