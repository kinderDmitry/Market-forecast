# Market Forecast PRO X 4.8.61

## Исправления

- Поиск: быстрый прямой поиск по BCS by-tickers + русские алиасы, включая ЦИАН/CIAN.
- Каталог BCS: отдельный search/scanner каталог, поддержка дополнительных типов, повтор при HTTP 429 и сохранение частично загруженного каталога.
- Сканер: отдельный universe без лишних облигаций/опционов, короткие исторические окна по таймфреймам, двухэтапное сканирование (история -> live quote только для кандидатов).
- Сканер больше не должен получать пустой universe из-за перегруженного общего каталога.
- Live price: исправлен выбор котировки — сначала ищется точное совпадение ticker + classCode, а не первый объект с полем `last`.
- Tracking/live price: удалён скрытый 15% clamp, который мог фиксировать цену на предыдущем значении.
- Version: 4.8.61 / versionCode 103.
