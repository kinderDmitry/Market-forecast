# Market Forecast PRO X 4.8.59

## Исправления

1. Поиск БКС
- Каталог БКС прогружается заранее в фоне.
- Исправлена остановка пагинации каталога при повторяющихся тикерах между страницами.
- Автоподстановка использует приоритет точного совпадения, начала тикера/названия и частичного совпадения.
- Сохраняется единый источник данных БКС без подмены котировок другим провайдером.

2. Таймфреймы
- Добавлен stale-while-revalidate: временная ошибка/лимит БКС больше не очищает уже загруженную историю таймфрейма.
- Исправлена критическая обработка H4: уже готовые 4-часовые свечи БКС больше не агрегируются повторно.

3. Цена и отслеживание
- Сохраняется единая canonical live price на инструмент независимо от выбранного таймфрейма.
- Защита от экстремального скачка котировки добавлена на уровне кэша live-цены.
- Уровни Entry/SL/TP продолжают рассчитываться от той же canonical live price.

4. Сканер
- Универсум сканера теперь классифицируется по типам БКС, поэтому в список акций не попадают валютные/прочие инструменты.
- Сканер использует отдельный admission-режим: сильный ансамблевый LONG/SHORT может быть показан даже если обычный прогноз заблокирован только историческим edge-gate. Направление не создаётся искусственно: требуются score и подтверждение.
- Статус сканера теперь явно показывает количество проверенных инструментов, даже если подходящих сигналов нет.
