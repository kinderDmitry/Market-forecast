# Market Forecast PRO X 4.8.82 — личный кабинет и бесплатный backend

- Добавлен экран «Личный кабинет».
- Реализованы регистрация, вход, выход и проверка текущей сессии.
- Добавлено серверное управление доступом: новый пользователь по умолчанию заблокирован.
- Первый аккаунт с email, совпадающим с `ADMIN_EMAIL`, получает роль администратора и активируется автоматически.
- Администратор видит список пользователей и может разрешать/закрывать доступ переключателем.
- При закрытии доступа активные сессии пользователя удаляются.
- Добавлен готовый backend `server/cloudflare`: Cloudflare Worker + D1 schema.
- GitHub можно использовать для хранения исходников и автоматизации деплоя; база и API работают на Cloudflare, а не на GitHub Pages.
- Версия: 4.8.82, versionCode 121.
