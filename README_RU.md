# Market Forecast PRO X 4.8.30

**Текущая версия:** 4.8.30 · `versionCode = 75`

## Аналитический центр 4.8.30

- Главная теперь строится вокруг ленты избранных акций и валют. Каждый инструмент получает отдельную live-карточку.
- В карточке есть мини-график движения цены, live-котировка и кнопки 15M / 1H / 4H / 1D / 1W.
- Цвет таймфрейма отражает фактический результат строгого аналитического фильтра: LONG — зелёный, SHORT — неоново-красный, NO TRADE — янтарный. Нажатие на таймфрейм открывает полный прогноз именно этого горизонта.
- Live-котировка обновляется независимо от тяжёлого пересчёта аналитики; полный пересчёт карточек выполняется примерно раз в минуту.
- Аналитическое ядро расширено CCI, Williams %R, MFI, CMF, Ichimoku, Donchian и Stochastic RSI.
- Введён строгий high-conviction gate: edge, разрыв LONG/SHORT, ADX, эффективность движения, подтверждение направления, расширенный теханализ и R/R должны одновременно пройти пороги. Иначе выдаётся NO TRADE.
- Важно: приложение не заявляет математическую гарантию результата — рыночный прогноз вероятностный. Цель строгого режима — отбрасывать слабые сетапы, а не превращать вероятность в ложную гарантию.

## Обновление поверх старого APK
Условия Android для обновления:
- Application ID должен совпадать: `com.marketforecast.prox`;
- сертификат подписи должен совпадать;
- `versionCode` новой версии должен быть выше.

В 4.8.27 сохранены Application ID и `signing/mfp-debug.keystore`, а `versionCode` повышен до 71. Поэтому APK должен устанавливаться поверх 4.8.15/4.8.17 без удаления приложения. Данные SharedPreferences при нормальном обновлении не очищаются.

Если старый APK был подписан другим сертификатом, Android потребует удалить старую установку — это ограничение Android, а не логики приложения.

## Важно по точности прогнозов
Приложение не может честно гарантировать, что цена через 15 минут или час обязательно будет LONG/SHORT. 4.8.27 повышает качество за счёт более строгого отбора и walk-forward проверки, но рыночный прогноз остаётся вероятностным.

Главный принцип проекта: лучше `NO TRADE`, чем слабый сигнал, искусственно названный точным.

## 4.8.27 — live prices и производительность
- MT5 не требуется и не настраивается пользователем: никаких IP/портов/серверов/логинов в приложении нет.
- БКС является единственным источником рыночных данных для прогнозов и сканера.
- Для глобальных инструментов используется автоматическая текущая котировка из публичного market-data feed; previousClose больше не используется как LIVE.
- Исторические свечи кэшируются на 30 секунд, котировки — на 5 секунд, чтобы уменьшить задержки и сетевую нагрузку.
- Chart/scale/Entry/SL/TP/S/R используют единую координатную модель.

Важно: бесплатный публичный feed не позволяет честно обещать непрерывный real-time для каждой мировой биржи. Поэтому приложение не подменяет live цену вчерашним close и должно явно показывать отсутствие текущей котировки.

## БКС Trade API — приоритетный источник цен (4.8.51)

В версии 4.8.53 БКС Trade API закреплён как единственный источник котировок/свечей для прогнозов и сканера. При наличии refresh-токена с правами **«Только для чтения»** приложение использует БКС для текущих котировок и исторических свечей поддерживаемых MOEX-инструментов. Это важно для устранения расхождений, когда аналитический центр, прогноз и разные таймфреймы показывали разные «текущие» цены.

### Как подключить
1. Откройте веб-версию **БКС Мир инвестиций**.
2. Откройте **Профиль → Счета и тарифы → нужный брокерский счёт → Токены API**.
3. Нажмите **Выпустить токен** и выберите права **«Только для чтения»**.
4. Скопируйте refresh-токен сразу после выпуска — БКС показывает его один раз.
5. В приложении откройте **Настройки → БКС — источник рыночных данных** и вставьте токен.
6. Нажмите **Сохранить токен БКС** и перезапустите приложение.

Токен для чтения не позволяет приложению выставлять заявки. Access-токен приложение получает автоматически; refresh-токен используется для его обновления.

### Что изменилось в сканерах
- **Обычный сканер:** поле ввода количества и единицы времени убраны. Он работает по своей логике сканирования, как раньше.
- **Сканер скриншотов удалён из интерфейса:** обычный рыночный сканер остаётся без выбора единицы времени/горизонта, как требовалось.
- Для **Авто** горизонт определяется самим движком по устойчивости визуального импульса.

### Важное ограничение
Даже более быстрый источник данных не делает прогноз гарантированным. БКС API предоставляет рыночные котировки, свечи и другие данные; точность прогноза зависит от ликвидности, задержки сети, состояния рынка и качества аналитической модели.
